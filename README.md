# Enchant Selector 1.12.2

Standalone Forge 1.12.2 enchantment selector inspired by the classic Not Enough Items enchantment screen.

## Target
- Minecraft 1.12.2
- Forge 14.23.5.2860
- Java 8

## Behavior
- Press **X** while an inventory/container GUI is open to open the selector.
- Put one item in the selector slot.
- **LOCKED**: shows only vanilla (`minecraft:`) enchantments that normally apply to that item.
- **UNLOCKED**: shows every registered enchantment, including modded enchantments, regardless of item type.
- Choose enchantment levels from **0 to 10**.
- Press **Apply** to write the selected enchantments while preserving the rest of the ItemStack data.
- Press **X** again to close the selector.
- The key is configurable in Minecraft Controls.

The mod is independent from NEI and JEI.
